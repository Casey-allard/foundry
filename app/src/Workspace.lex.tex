definition{
  name: workspaceWireBoundary,
  parameters: [],
  result: String,
  body: "Requests use workspace-space then lowercase little-endian uint32 hex words: version 1; the kind (0 open, 1 read a record, 2 store a record, 3 move the workspace kept before an id, 4 remove its plain copy); then one word per fact, 1 for yes and any other value for no. Open: this device was removed, the session is live, the id owns the workspace, the device holds the current boundary key. Read: the workspace is open, the sealed bytes are authentic, the record is the one its place names. Store: open, sealed, within quota. Move: open, already moved. Remove: open, the sealed copy is committed. The answer is ok or the first refusal: workspaceDeviceRemoved, workspaceSessionExpired, workspaceNotOwner, workspaceKeyStale, workspaceClosed, recordTampered, recordMisplaced, recordUnsealed, workspaceQuotaExceeded, workspaceAlreadyMoved, sealedCopyNotCommitted. Any other shape is malformedWorkspaceRequest, and more than 128 bytes is workspaceRequestTooLarge."
}
